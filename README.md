One Letter for Your Day. The entry is one letter, `U`, standing for "unhinged":
a vivid, funny, true word for the day. No gloss, no punctuation, just the initial.

## Run it

```sh
python3 -P -s main.py
```

The program writes exactly one byte, `U`, to `/output/entry.txt` with no trailing
newline. Set `MAKEFUN_OUTPUT_DIR` to write somewhere else. It uses only the
Python standard library and reads nothing from outside this repository.
